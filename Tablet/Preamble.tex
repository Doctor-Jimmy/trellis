\begin{definition}
The shared Lean environment imports the natural numbers with their standard
linear order, order embeddings, finite-prefix function notation, and iterates
of a self-map.  In particular, an order embedding $\mathbb N\hookrightarrow
\mathbb N$ is an injective order-preserving map, and $f^{[n]}$ denotes the
$n$-fold iterate of $f$.
\end{definition}

\begin{definition}
Finite subsets of $\mathbb N$ are represented by `Finset $\mathbb N$`, and
subsets of $\mathbb N$ by `Set $\mathbb N$`.  The imported set library
provides the predicate that a subset is infinite, together with the usual
finite-set and set-theoretic operations used below.
\end{definition}

\begin{proposition}
The imported order library supplies the standard facts that strict monotone
maps between linearly ordered types are order embeddings and that
$\mathsf{WellQuasiOrdered}(r)$ is the sequence-based well-quasi-ordering
predicate for a binary relation $r$.
\end{proposition}
