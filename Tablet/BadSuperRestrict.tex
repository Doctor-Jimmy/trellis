\begin{lemma}[Badness under sub-front restriction]
If a super-sequence is bad, then its restriction to any sub-front is bad.
\end{lemma}
\begin{proof}
Every finite shift between members of the restricted front is also a finite
shift between members of the original front.  The restricted value map is
the original value map composed with the inclusion, by
\noderef{SuperSequenceRestrict}.  Apply badness of the original sequence.
\end{proof}
