\begin{definition}
For a carrier $Q$, the full non-empty iterated powerset presentation
$\mathsf{PowerQ}(Q)$ is the inductive type generated by two disjoint tags.
An atom is a member $q\in Q$.  A node consists of an arbitrary nonempty
small index type $\iota$ and a family
$(X_i)_{i\in\iota}$ of already constructed presentations.  Thus a node
represents the nonempty set of its children, while the atom tag ensures that
an element of $Q$ is never confused with a set node.
\end{definition}
