\begin{lemma}[Initial bridge]
Let $F$ be a front on $\mathbb N$ with $\emptyset\notin F$.  If
$m<n$, then
\[
  \mathsf{FrontBridge}\bigl(F,\{m\},\{n\},\{m,n\}\bigr).
\]
\end{lemma}
\begin{proof}
By \noderef{FrontTreeSingleton}, both singletons belong to $T(F)$.
The set $\{m,n\}$ is nonempty, and its least element is $m$, so by the
finite-tail definition \noderef{FrontBridgeTail} its bridge tail is the
nonempty singleton $\{n\}$.  If $\{m\}\notin F$,
then the displayed bridge point is exactly $n$:
\[
 \{m,n\}=\operatorname{insert}(n,\{m\}),
\]
and $m<n$ makes $\{m\}$ an ordered proper initial segment of this
one-point extension.  The latter belongs to $T(F)$ by the ordered
one-point extension theorem \noderef{FrontTreeOrderedExtension}.  If
$\{m\}\in F$, the required left initial-segment clause holds by equality.
The same two alternatives for $\{n\}$ give either equality with the
bridge tail or the terminal initial-segment clause.  Thus the right node
is nonempty as required.  These are precisely all clauses of
\noderef{FrontBridge}, so the displayed bridge state holds.
\end{proof}
