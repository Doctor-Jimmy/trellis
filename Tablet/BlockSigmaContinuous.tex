\begin{lemma}
For fixed $g$ and $k<g(k)$, the map $f\mapsto\sigma_f$ is
prefix-continuous.  Explicitly, for every $f$ and every output length $n$,
some finite prefix of $f$ determines all values
$\sigma_f(l)$ for $l<n$.
\end{lemma}
\begin{proof}
Fix $f$ and $n$.  By \noderef{OrbitBlockCoverage}, each $l<n$ is either
below $G(0)$ or lies in a unique block with index at most the largest block
met before $n$.  In the latter case the value of $\sigma_f(l)$ depends only
on the finitely many values $f(i)$ for those block indices.  Choose an input
prefix long enough to include all of them.  If $h$ agrees with $f$ on this
prefix, the same block cases and the same iterates are selected for every
$l<n$, so $\sigma_h(l)=\sigma_f(l)$.  This is exactly
$\mathsf{BaireContinuous}$ for the coordinatewise map.
\end{proof}
