\begin{definition}
An element $x\in\mathsf{PowerQ}(Q)$ is hereditarily countable when it is
presentation-equivalent to the erasure of a countable presentation code.
Thus atoms are allowed, and every set node has a countable nonempty family
of children, each of which is again represented by such a code.  The
definition is made by presentation equivalence, rather than by selecting a
particular raw presentation.
\end{definition}
