\begin{lemma}[Moves stay in support]
Every legal move stays in the support of the presentation from which it is
made:
\[
\mathsf{PowerMove}(x,x')\Longrightarrow
\mathsf{PowerSupport}(x')\subseteq\mathsf{PowerSupport}(x).
\]
\end{lemma}
\begin{proof}
By \noderef{PowerMove}, if $x$ is an atom then $x'=x$, and \noderef{PowerSupport}
gives the atom support clause, so the inclusion is equality.  If $x$ is a
node, the same definition says that $x'$ is a child of $x$.  Apply the support
inclusion from \noderef{PowerChildSupport}.
\end{proof}
