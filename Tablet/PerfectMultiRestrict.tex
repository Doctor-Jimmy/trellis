\begin{lemma}[Perfectness under restriction]
If a multi-sequence is perfect, then every sub-multi-sequence obtained by
restriction along an increasing embedding is perfect.
\end{lemma}
\begin{proof}
Evaluate the original perfectness assertion at $x\circ z$.  The second
value is the shift of this enumeration, and \noderef{RestrictionShift}
identifies it with the shifted value of $h\mathbin{|}z$.  This is exactly
the definition of \noderef{PerfectMultiSequence}.
\end{proof}
