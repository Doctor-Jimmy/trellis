\begin{lemma}[Multi-sequence perfectness gives super-sequence perfectness]
If $h$ is perfect and $h^{\dcl}$ is its induced value map on the deciding
front, then $h^{\dcl}$ is perfect as a super-sequence.
\end{lemma}
\begin{proof}
Put $F=\mathsf{DecidingFrontSet}(h)$.  We prove the defining implication
of \noderef{PerfectSuperSequence}.  Fix finite sets $s,t\subseteq\mathbb N$,
membership proofs

\[
 h_s:s\in F\qquad\text{and}\qquad h_t:t\in F,
\]

and assume $s\mathrel{\mathsf{FiniteShift}}t$.  The membership proofs are
exactly the front-membership data supplied by \noderef{DecidingFrontSet},
so they determine the two subtype elements
$\langle s,h_s\rangle$ and $\langle t,h_t\rangle$ on which the value
field of the super-sequence \noderef{SuperSequence} is evaluated.

Unpack the assumed finite shift using \noderef{FiniteShift}.  There is an
increasing enumeration $x\in\mathsf{IncSeq}$ such that

\[
 \mathsf{ProperPrefixSet}\bigl(s,\operatorname{range}(x)\bigr)
 \quad\text{and}\quad
 \mathsf{ProperPrefixSet}\bigl(t,
       \operatorname{range}(\mathsf{ShiftMap}(x))\bigr).
 \tag{1}
\]

Here $\mathsf{ShiftMap}(x)$ is again an increasing enumeration by the
definition of \noderef{ShiftMap}; the two displayed assertions are the two
conjuncts in the definition of the finite-shift witness, with the second
one using precisely the shifted enumeration.

Apply the local coherence hypothesis $hf$ for the induced value map first to
$\langle s,h_s\rangle$ and $x$.  The first assertion in (1) gives

\[
 f.value\langle s,h_s\rangle=h(x).
 \tag{2}
\]

Apply the same hypothesis $hf$ to $\langle t,h_t\rangle$ and
$\mathsf{ShiftMap}(x)$.  The second assertion in (1) gives

\[
 f.value\langle t,h_t\rangle=h(\mathsf{ShiftMap}(x)).
 \tag{3}
\]

Since $h$ is perfect, the defining condition in
\noderef{PerfectMultiSequence}, instantiated at this particular $x$,
gives

\[
 r\bigl(h(x),h(\mathsf{ShiftMap}(x))\bigr).
 \tag{4}
\]

Finally rewrite the first argument of (4) using (2) and the second using
(3), in the displayed directions.  We obtain

\[
 r\bigl(f.value\langle s,h_s\rangle,
        f.value\langle t,h_t\rangle\bigr).
\]

Because $s,t,h_s,h_t$ and the finite-shift assumption were arbitrary, this
is exactly the implication required by
\noderef{PerfectSuperSequence}.  Hence $f$ is perfect as a
super-sequence.
\end{proof}
