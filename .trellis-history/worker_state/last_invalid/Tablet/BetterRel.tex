\begin{definition}
A binary relation $R$ on a discrete type $A$ is a better-relation if there
is no continuous homomorphism
\[
(\mathsf{IncSeq},\mathsf{ShiftMap})
\longrightarrow (A,R^{\complement}).
\]
Here $R^{\complement}(a,b)$ means exactly $\neg R(a,b)$, and continuity
means local constancy on finite prefixes.
\end{definition}
