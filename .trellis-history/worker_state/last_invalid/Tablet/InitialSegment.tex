\begin{definition}
For finite subsets $u,v\subseteq\mathbb N$, write
$\mathsf{InitialSegment}(u,v)$ if either $u=v$, or there is an $n\in v$
such that
\[
u=\{k\in v\mid k<n\}.
\]
Thus this is the paper's initial-segment relation after identifying a finite
set with its increasing enumeration.
\end{definition}
