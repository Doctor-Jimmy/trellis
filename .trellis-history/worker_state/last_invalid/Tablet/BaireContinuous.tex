\begin{definition}
A map $F:\mathsf{IncSeq}\to\mathsf{IncSeq}$ is prefix-continuous if for
every $x\in\mathsf{IncSeq}$ and every output length $n$ there is an input
length $k$ such that agreement of an input $y$ with $x$ through $k$ forces
agreement of $F(y)$ with $F(x)$ through $n$.
\end{definition}
