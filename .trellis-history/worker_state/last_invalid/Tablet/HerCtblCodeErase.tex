\begin{definition}
The erasure of a countable presentation code into the full hierarchy is
defined recursively.  An atom erases to the corresponding tagged atom.  A
code node erases to a $\mathsf{PowerQ}$ node whose index type is
$\mathsf{ULift}(\mathbb N)$, which lies in the universe required by
$\mathsf{PowerQ}$, and whose children are the erasures of the coded family.
\end{definition}
